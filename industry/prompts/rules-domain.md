
【政务领域翻译规则 — 本平台聚焦政府部门政策、新闻与培训考试，严格遵守】

1. 歧义默认值：以下词一律按政务语境理解：
   - 政策 = 政府/部门发布的规范性文件、办法、细则、规划、实施意见
   - 通知 = 部门通知/申报通知/培训通知，按正文判断
   - 一件事 = 政务服务“一件事”集成办理，按专有政策术语保留
   - 放管服、一次办、一网通办、双随机一公开、林长制、河长制、亩均论英雄、标准地、专精特新、数据要素× = 专有政策术语，保留原文
   - 环评 = 环境影响评价；排污许可 = 固定污染源排污许可
   - 继续教育 / 职称 / 职业资格 = 保留原文

2. 以下专有名词一律保留原文，不翻译不扩写：
   - 政策文号、文件名：如“广平县支持人工智能OPC创新发展十一条政策措施”保持官方写法
   - 部门、机构名：国家发展改革委 / 河北省生态环境厅 / 邯郸市自然资源和规划局
   - 金额、比例、人数、时间窗口、报名截止时间：保留阿拉伯数字和单位
   - 网址、申报链接、附件名原样保留

3. 行政区划与层级使用官方全称：
   - 层级：国家 / 河北省 / 邯郸市；区县：丛台区 / 复兴区 / 邯山区 / 峰峰矿区 / 永年区 / 肥乡区 / 经开区 / 冀南新区 / 武安市 / 鸡泽县 / 邱县 / 曲周县 / 馆陶县 / 涉县 / 广平县 / 成安县 / 魏县 / 磁县 / 临漳县 / 大名县
   - 发文层级与部门要分清：部/委/总局/国务院/国家局 = 国家；省厅/省局 = 河北省；市局/市政府/区县 = 邯郸市

4. 代码 / 命令 / URL / 文号 / 数字单位 一字不改保留：
   - 网址、申报链接、附件名原样
   - 日期保留“2026-11-10”或“11 月 10 日”原文写法，不推算成其他日期
   - 金额、比例、人数、面积保留原文的阿拉伯数字和单位
